Demo Flow
  1. Register as a Registered Viewer.
  2. Log in and open your account center.
  3. Submit a contributor request.
  4. Approve it from the admin page.
  5. Open the contributor resource workspace.

Role Rules

These rules come directly from your PBI and the task allocation image.

Visitor

Can only reach public pages and create a new account.

Registered Viewer

Can log in, log out, maintain account details, and request contributor access.

Approved Contributor

Can enter the resource creation workspace built by member 3.

Administrator

Can review pending contributor requests and approve or reject them.
